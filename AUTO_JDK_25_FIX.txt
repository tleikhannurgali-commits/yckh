StorageESP Forge 1.21.11 — устранена ошибка Java 25 Mavenizer

Что исправлено:
- settings.gradle подключает официальный Foojay toolchain resolver для Gradle 9.5.
- ForgeGradle 7 запускает Mavenizer на JDK 25; Gradle теперь может скачать JDK 25 автоматически.
- build.gradle сохраняет target JDK 21, необходимый Minecraft 1.21.11.

Действия:
1. Распакуйте проект и откройте папку StorageESP.
2. Оставьте установленную Temurin JDK 21 и доступ к интернету.
3. Запустите BUILD_MOD.cmd.
4. После успешной сборки ищите файл .jar в build\libs.
5. При ошибке запустите RUN_DIAGNOSTICS.cmd из предыдущего сообщения или сохраните полный вывод Gradle.

Внимание: полная компиляция проекта в этой среде не выполнялась. Изменение убирает
ошибку отсутствующего toolchain repository для JDK 25, но могут быть другие ошибки.
Если автоматическая загрузка JDK не работает, можно поставить Temurin JDK 25
параллельно с JDK 21. Не делайте JDK 25 версией по умолчанию для BUILD_MOD.cmd:
его текущая проверка требует, чтобы команда java -version показывала JDK 21.

StorageESP — КАК ПОЛУЧИТЬ .JAR

Это ИСХОДНИКИ мода для Minecraft Java 1.21.11 / Forge 61.2.5.
Ранее в сборке была ошибочно выбрана Java 25. Исправлено на Java 21.

СПОСОБ 1 — GitHub Actions (можно без Java и Gradle на компьютере):
1. Создайте отдельный репозиторий StorageESP на GitHub.
2. Извлеките ZIP. Загрузите всё содержимое папки StorageESP,
   включая скрытую папку .github и папку src, в корень репозитория.
3. Нажмите Commit changes.
4. Откройте Actions -> Build Storage ESP 1.21.11.
5. Если сборка зелёная, скачайте Artifacts -> StorageESP-Forge-1.21.11.
6. Распакуйте артефакт: внутри будет .jar, если сборка прошла успешно.

СПОСОБ 2 — На Windows:
1. Установите JDK 21, убедитесь, что команда java -version показывает 21.
2. Запустите BUILD_MOD.cmd в распакованной папке.
3. Скрипт скачает Gradle 9.5.0 и зависимости Forge.
4. При успехе готовый .jar лежит в build\libs.
5. При ошибке отправьте build-log.txt.

ДЛЯ ИГРЫ: загрузчик Forge 61.2.5 + Minecraft 1.21.11, а не Fabric!
Прежде чем переносить .jar в mods, проверьте, что сборка успешна.
